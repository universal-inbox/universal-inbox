# Completions

Per-task completion docs — one file per finished task, created from
[completion-template.md](../templates/completion-template.md).

**NEVER auto-loaded.** This folder is git/claude-ignored, so it adds **zero
session-start token cost**. Read a file here only when explicitly referenced.

**Naming:** `YYYY-MM-DD-short-task-slug.md`
(e.g. `2026-05-30-slack-rendering-fix.md`).

See [DOCUMENTATION_MAINTENANCE.md](../DOCUMENTATION_MAINTENANCE.md) for when to
write one, and [comprehensive guide](../../AGENTS.md) for deep detail.
