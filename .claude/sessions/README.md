# Sessions

In-progress, multi-session work logs scaffolded from
[session-template.md](../templates/session-template.md). Track context that must survive across
several Claude Code sessions on the same piece of work.

**NEVER auto-loaded.** This directory is git/claude-ignored and read only on explicit request.

## Layout

- `active/` — work logs for sessions currently in progress.
- `archive/` — logs for work that has shipped.

## Workflow

1. Start a new log in `active/` from [session-template.md](../templates/session-template.md).
2. Update it at the end of each session with state and next steps.
3. Move it to `archive/` once the work ships.
